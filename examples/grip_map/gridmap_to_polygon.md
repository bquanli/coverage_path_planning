# `gridmap_to_polygon.cc` 算法说明

这个示例将一张栅格地图中的自由空间转换为多个带孔洞的多边形，并导出预览图和 JSON。每个独立的自由空间区域对应一个多边形，区域内部被包围的障碍物或未知区域对应孔洞。

它完成的是地图的几何表示转换，不涉及覆盖路径生成、路径搜索或机器人运动控制。以下说明仅依据 `examples/gridmap_to_polygon.cc`。

## 1. 整体流程

```text
构造示例栅格地图，保存为 gridmap.png
                  ↓
以灰度图读回，提取灰度值恰好为 255 的自由栅格
                  ↓
提取轮廓及其层级，组织成「外环 + 孔洞」
                  ↓
简化各个环，并统一顶点排列方向
                  ↓
按外环面积从大到小排序
                  ↓
输出自由空间掩码、轮廓预览图和多边形 JSON
```

算法在像素坐标中完成轮廓提取、简化和排序；世界坐标只在写入 JSON 时计算。

## 2. 输入地图与数据结构

`make_gridmap()` 创建一张宽 720、高 480 的单通道灰度图，使用以下约定：

| 像素值 | 含义 | 是否参与自由空间轮廓提取 |
| --- | --- | --- |
| 0 | 已占据区域 | 否 |
| 127 | 未知区域 | 否 |
| 255 | 自由区域 | 是 |

地图先以未知区域填充，再绘制占据背景、两个互不连通的自由房间和内部障碍物：

- 主房间具有凹边界，内部有一个矩形障碍物和一个圆形障碍物。
- 右侧房间内部有一个三角形障碍物。
- 主房间上边缘放置了一块未知区域，形成边界缺口。

这些形状用于展示凹多边形、多个独立区域、孔洞，以及未知区域对边界的影响。

几何数据结构很简单：

```cpp
using Ring = std::vector<cv::Point>;

struct Polygon
{
  Ring outer;
  std::vector<Ring> holes;
};
```

`Ring` 存放整数像素坐标顶点。`outer` 表示外边界，`holes` 表示内部孔洞。环采用隐式闭合约定，即最后一个顶点与第一个顶点相连，无须额外重复首点。

## 3. 提取自由空间掩码

`main()` 将生成的地图保存后重新读入，用来演示完整的“图像文件 → 多边形”过程。随后执行：

```cpp
cv::compare(input, 255, free_mask, cv::CMP_EQ);
```

这一步产生二值图：输入像素等于 255 时，掩码为 255；其余位置为 0。因此，占据区域和未知区域都会被排除。

这里使用严格相等判断，没有灰度阈值、去噪、形态学处理或障碍物膨胀。如果改用其他来源的地图，需要先确认其像素编码是否符合这一约定。

## 4. 从轮廓层级构建多边形

`extract_polygons()` 调用：

```cpp
cv::findContours(free_mask.clone(),
                 contours,
                 hierarchy,
                 cv::RETR_CCOMP,
                 cv::CHAIN_APPROX_SIMPLE);
```

`contours` 保存边界点序列，`hierarchy` 保存轮廓之间的关系。传入掩码副本，使轮廓提取使用独立的图像数据。

`CHAIN_APPROX_SIMPLE` 压缩水平、垂直及对角直线段上的冗余点，减少轮廓点数；它与后面的多边形近似是两个不同阶段。

`RETR_CCOMP` 将轮廓组织为两层结构：顶层是自由区域的外边界，子层是该区域内部孔洞的边界。如果孔洞中还有自由空间岛，该岛也会作为顶层外边界，生成一个独立多边形。

每个 `hierarchy[i]` 的四个元素依次表示：

| 下标 | 含义 |
| --- | --- |
| 0 | 下一个同级轮廓 |
| 1 | 上一个同级轮廓 |
| 2 | 第一个子轮廓 |
| 3 | 父轮廓 |

索引为 `-1` 表示不存在对应关系。代码按以下方式组装多边形：

1. 遍历全部轮廓，仅将父索引为 `-1` 的轮廓作为外环。
2. 从该外环的第一个子轮廓开始，沿“下一个同级轮廓”遍历，将它们加入孔洞列表。
3. 将外环与孔洞一起存入 `polygons`。

孔洞归属由轮廓层级直接确定，不需要再自行做点在多边形内的判断。外层循环跳过孔洞，是因为它们已在所属外环的子轮廓遍历中处理。

需要区分“内部孔洞”和“边界缺口”：完全被自由空间包围的非自由区域会形成孔洞；与外部非自由区域连通的部分会改变外环形状。示例中，上边缘的未知矩形属于后者。

## 5. 简化边界并统一环方向

### 5.1 多边形近似

`simplify_ring()` 对外环和每个孔洞分别执行：

```cpp
cv::approxPolyDP(contour, ring, epsilon_pixels, true);
```

这是 Douglas–Peucker 多边形近似。其基本思想是用较少的线段表示原始轮廓：当一段轮廓可以在指定误差内由直线近似时，省略中间点；否则保留偏离较大的点并继续细分。这里最后一个参数 `true` 指定按闭合轮廓处理。

`epsilon_pixels = 2.0` 控制近似精度，单位为像素。地图分辨率为 0.05 米/像素，因此这一容差在尺度上对应 0.10 米。它约束的是轮廓近似精度，不能直接当作机器人与障碍物之间的安全距离。

矩形等直线边界通常只需要少量顶点；圆形障碍物则会变成由多条线段组成的孔洞边界。增大容差通常会减少顶点，同时损失更多细节。

简化后，如果顶点数少于 3，或面积等于 0，函数抛出异常。程序会终止并报告错误，而不是忽略该退化轮廓。

### 5.2 环方向

图像坐标的 Y 轴向下，世界坐标的 Y 轴向上。转换时翻转 Y 轴，会使环的有向面积符号反转。

代码使用 `cv::contourArea(ring, true)` 获取有向面积，并在必要时反转顶点顺序：

```cpp
if((cv::contourArea(ring, true) > 0.0) != hole)
{
  std::ranges::reverse(ring);
}
```

最终约定如下：

| 环类型 | 像素坐标下的有向面积 | 转为世界坐标后的方向 |
| --- | --- | --- |
| 外环，`hole == false` | 负 | 逆时针 |
| 孔洞，`hole == true` | 正 | 顺时针 |

这样导出的世界坐标多边形具有统一方向，便于后续几何算法使用。

## 6. 多边形排序

所有多边形构建完成后，代码使用 `std::ranges::stable_sort`，按 `cv::contourArea(a.outer)` 从大到小排序。默认返回无符号面积，因此这里不受环方向影响。

这里比较的是简化后外环围成的面积，没有减去孔洞面积。严格地说，它是“外环面积排序”，不是实际可通行净面积排序。稳定排序会保留面积相等元素原来的相对顺序，但并不提供跨不同地图的固定区域编号。

排序后的下标用于预览标签 `P0`、`P1` 等。按示例构造，预期得到两个多边形：主房间排在前面，含两个孔洞；右侧房间含一个孔洞。

## 7. 从像素坐标转换到世界坐标

`write_ring()` 为每个环同时写出 `pixels` 和 `world_m` 两组坐标。设像素坐标为 `(u, v)`，图像高度为 `H`，则：

```text
x_world = origin_x + (u + 0.5) × resolution
y_world = origin_y + (H - v - 0.5) × resolution
```

本例参数为：

```text
resolution = 0.05 米/像素
origin_x   = -2.0 米
origin_y   = -1.0 米
H          = 480
```

其中，`(origin_x, origin_y)` 表示图像左下角在世界坐标中的位置；`0.5` 偏移把栅格索引换算为栅格中心坐标；`H - v - 0.5` 同时完成 Y 轴翻转和中心偏移。

例如，左下角像素 `(0, 479)` 的中心对应世界坐标 `(-1.975, -0.975)` 米。整个栅格地图的物理尺寸为 36 米 × 24 米。

这里有一个重要限制：提取的轮廓点位于边界像素的中心，随后还经过近似简化；它们不是沿栅格单元外边缘构造的精确几何边界。因此，导出的多边形不能视为自由栅格单元并集的精确外轮廓。

## 8. 输出与程序入口

程序允许一个可选命令行参数，用于指定输出目录，默认是 `examples/gridmap_polygon_output`。这个参数不是输入地图路径；当前示例始终自行构造地图，再读回生成的图片。

| 输出文件 | 内容 |
| --- | --- |
| `gridmap.png` | 包含自由、占据和未知区域的原始示例地图 |
| `free_mask.png` | 仅将自由区域标白的二值掩码 |
| `preview.png` | 左侧为原始地图，右侧叠加外环、孔洞、顶点和区域编号 |
| `polygons.json` | 地图参数，以及每个多边形外环和孔洞的像素坐标、世界坐标 |

`make_preview()` 用青绿色绘制外环、橙色绘制孔洞，并在简化后的顶点上画圆点。`draw_ring()` 绘制闭合折线，因此预览能够直观展示近似后的几何形状。

`save_polygons()` 使用 OpenCV 的 `FileStorage` 输出 JSON，记录宽高、分辨率、原点、简化容差和隐式闭合标志。每个多边形包含 `outer` 和 `holes`，每个环包含 `pixels` 和 `world_m`。

程序最后打印多边形数量、各外环顶点数和孔洞数。读取失败、写入失败或轮廓退化等异常统一由 `main()` 捕获，输出错误并返回 1；成功返回 0。传入 `--help` 会显示用法。

## 9. 使用结果时需要注意的边界

这份代码适合演示从二值自由空间提取带孔多边形的基本方法。将其结果用于后续规划时，需要结合以下实现特点理解：

- 自由空间完全由像素值是否等于 255 决定；未知区域不被当作可通行区域。
- 没有机器人尺寸或安全间距处理，得到的是地图层面的自由空间。
- 外环和孔洞独立简化，代码只检查顶点数和零面积，没有进一步验证简化后的环间相交、孔洞包含关系或狭窄通道是否保留。
- 像素中心轮廓与精确栅格边缘存在差别，多边形近似也会改变局部边界位置；代码没有保证近似结果始终保守地落在原始自由空间内部。
- JSON 中的环按隐式闭合保存，使用方需要将末点与首点连接。

这些限制决定了该示例输出的是一种简洁的自由空间几何表示；若后续需要严格的碰撞检测或覆盖规划，还需按应用要求处理地图、边界精度和几何有效性。
